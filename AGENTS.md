# Repository authoring rules

These rules govern work on this collection, not permission to modify an analyzed project.

- Follow `docs/skill-style-guide.md` before changing skills. Author: AlvarezTDV; license: Apache-2.0. Keep the single root LICENSE and applicable NOTICE with standalone distributions.
- Register and maintain the catalog below. Do not publish `.atl/`, local paths, credentials or private project data.
- Keep shared idea/state semantics in brainstorm. Companions locate the installed primary by name and read its precise reference files, not a second divergent copy.
- Keep instructions/templates English; direct each skill to render user-facing text and output documents in the current session language.
- Preserve the standalone core, optional follow, consent-only perf, authoritative individual idea document and no-original-mutation boundaries.
- Run `python -B -m unittest discover -s tests -v` and `git diff --check`. Structural success is not runtime certification. Document actual scenario evidence and unavailable proof honestly.
- Use reviewable Conventional Commits without AI attribution. Publishing and installation require separate authorization.
